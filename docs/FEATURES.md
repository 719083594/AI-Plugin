# 功能范围与路线

57 项保留原有 A–K 编号，表示保留在产品范围或后续路线中。`implemented` 只确认本页所述范围；部分完成的复合功能按 `planned` 标注。初始示例没有模型渠道，不应把“代码已实现”当成“当前服务已配置”。

本版已接入外部 VITS 文字转语音与语音回复，默认仍发送文字。自动提取记忆、向量知识库、MCP、Skills、工作流、语音识别、视频、完整文档解析、Cloud 或 PostgreSQL 尚未实现。计划功能在 Orange 显示状态说明，不提供无效开关。

| A2 | 群聊 @ 回复 | 已实现（见范围） | 云崽适配器支持群聊 @ 触发，独立核心不依赖群平台。 |
| A3 | 命令前缀与角色前缀 | 已实现（见范围） | 支持管理命令前缀、群聊提问前缀和每个角色的提问前缀。 |
| A4 | 多轮聊天与结束会话 | 已实现（见范围） | 持久多轮历史；可结束自己的会话，主人可结束全部。开始新会话仍保留原历史。 |

| A6 | 读取近期群聊 | 已实现（见范围） | 保存并读取近期群聊文字；适配器可在首次请求时采集协议端近期历史。 |
| A7 | 引用、长回答与富媒体回复 | 待完整实现 | 已处理引用文字、引用图片和普通富媒体回复；长文自动分段、合并转发与完整富媒体策略尚未实现。 |
| A8 | 展示模型返回的思考内容 | 已实现（见范围） | 可以展示服务实际返回的结构化 reasoning；默认隐藏，普通正文中的思考标签会过滤。此开关不会启用模型额外推理预算。 |

## 配置生效与验证

普通模型、角色、权限、提示词、数据保留策略等在下一轮请求读取。服务地址、端口、认证和登录周期、队列大小、图片大小/TTL、清理周期与自定义工具代码由运行实例持有，修改后重启。

协议单元测试验证请求、响应和错误契约；实际渠道、QQ 平台行为和外部搜索服务还需要在实例中验收。健康检查只检查服务与本地配置，不会调用收费模型，也不会向 QQ 发消息。
