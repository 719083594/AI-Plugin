# 自动指令知识库

安装 OrangeJuice-Plugin 后，AI 会自动把 `#指令表` 的全部已加载指令保存为 `data/knowledge/commands.md`，并按指令导入 SQLite 知识库。原有手工知识保留。

私聊直接问“你能干什么”；群聊按现有 AI 触发方式 @ 机器人提问，例如“怎么查天气”“群里怎么禁言”“有什么功能”。AI 会结合问题挑选实际指令和用法，不执行管理操作。

插件加载、更新、卸载、指令前缀及自定义指令变更后，OrangeJuice 每 5 秒更新源文件 `data/orangejuice/command-catalog.json`，AI 每 15 秒检查并覆盖旧条目。需要重启才能加载的插件先按框架正常重启；未加载的插件不会被推荐。回答前重新读取当前聊天的指令范围，不使用过期菜单。

帮助公开；主人私聊指令不进入群聊回答。管理员、群主功能按框架主人身份或 OneBot 成员查询结果筛选，查询失败按公开权限处理。管理操作仍由原插件校验权限。自动生成的全文档包含主人指令，仅保存在服务器本地，普通文本检索不会读出这些条目。

`memory.commandKnowledgeEnabled` 默认 `true`，独立于手工资料检索的 `memory.knowledgeEnabled`。自动同步不调用模型、搜索或 Embedding；提问时仅把相关指令加入模型上下文。没有 OrangeJuice 时，AI 的其他功能照常使用。
